#### work

<a href="https://github.com/tejas242/sift"><img src="assets/logos/sift.svg" width="18" height="18" align="top"></a> **[sift](https://github.com/tejas242/sift)** &nbsp;`Go · 2026`<br>
Semantic search over your code, docs and notes, from the terminal, with nothing leaving the machine. Embeds on the CPU and searches an HNSW graph written from scratch.

<a href="https://github.com/tejas242/distributed-broadcast"><img src="assets/logos/distributed-broadcast.svg" width="18" height="18" align="top"></a> **[distributed-broadcast](https://github.com/tejas242/distributed-broadcast)** &nbsp;`Go · 2026`<br>
A gossip broadcast node for Jepsen's Maelstrom that stays available and eventually consistent through network partitions.

<a href="https://github.com/tejas242/ArQiv"><img src="assets/logos/arqiv.svg" width="18" height="18" align="top"></a> **[ArQiv](https://github.com/tejas242/ArQiv)** &nbsp;`Python · 2025`<br>
A search engine for arXiv that layers boolean, BM25, TF-IDF, vector and BERT ranking over one index. [Try it](https://arqiv-search.streamlit.app/).

<a href="https://github.com/tejas242/search-engine-go"><img src="assets/logos/search-engine-go.svg" width="18" height="18" align="top"></a> **[search-engine-go](https://github.com/tejas242/search-engine-go)** &nbsp;`Go · 2026`<br>
A small, thread-safe document search engine on an inverted index.

<a href="https://github.com/tejas242/arxiv-mcp"><img src="assets/logos/arxiv-mcp.svg" width="18" height="18" align="top"></a> **[arxiv-mcp](https://github.com/tejas242/arxiv-mcp)** &nbsp;`Python · 2025`<br>
